# SkillStack Guidelines

> [!NOTE]
> SkillStack is a production TanStack Start application built with React, Vite, TypeScript, and Tailwind CSS.

## Key Rules for AI Agents & Developers

1. Maintain standard TanStack Start & React 19 structure.
2. Keep design system consistent with SkillStack dark/gold aesthetic (`src/styles.css`).
3. Run `npm run lint`, `npx tsc --noEmit`, and `npm run build` after making changes.
