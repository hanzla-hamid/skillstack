# SkillStack — Skills Institute Platform

SkillStack is a premium hybrid skills institute platform offering courses in Web Development, Graphic Design, Digital Marketing, and E-Commerce.

## Technical Architecture

- **Framework**: TanStack Start (SSR & Hybrid Routing)
- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS v4, Radix UI, Framer Motion
- **Build System**: Vite 8, Nitro
- **Backend / Database**: Supabase (Auth, PostgreSQL, Row Level Security)

## Local Development

```sh
npm install
npm run dev
```

## Available Scripts

- `npm run dev`: Start local development server
- `npm run build`: Build production assets for SSR & Cloudflare
- `npm run lint`: Run ESLint checks
- `npm run format`: Format code using Prettier
